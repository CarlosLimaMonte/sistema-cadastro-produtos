# Sistema de Cadastro de Produtos

Sistema desenvolvido em Java para cadastro e exibição de produtos físicos e digitais no terminal.

## Conceitos aplicados

- Orientação a Objetos — classes, herança, encapsulamento, polimorfismo
- Interface
- ArrayList e coleções

## Como rodar

1. Clone o repositório
   git clone https://github.com/CarlosLimaMonte/sistema-cadastro-produtos

2. Abra no IntelliJ IDEA

3. Rode a classe Main

## Tecnologias

- Java 17+
- IntelliJ IDEA
